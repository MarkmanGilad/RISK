# Retired learning experiments

This directory is a removable archive, not part of the active project.

- `code/` contains the ADQN and PQN implementation modules.
- `tests/` contains their focused tests.
- `docs/` contains the ADQN, PQN, VQN, and Policy Duel DQN design records.

The active learner set is DQN, Dueling DQN, and PPO. The live training factory,
constants, logger, tests, and documentation no longer import or describe these
retired experiments.
